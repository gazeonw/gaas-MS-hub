# 黄执中《行为说服》· 知识卡片

> 来源：Maggie Qin 的金山文档学习笔记（kdocs 分享），2026-10-09 提炼入库。原文档约 1000 字大纲式笔记，本卡片忠实保留原文框架，辅以书单注解。

## 一、核心边界：行为说服 ≠ 人际说服

- **人际说服解决「想不想」，行为说服解决「做不做」**
- 人际说服：对象是态度/认知/认同，落点是"他嘴上同意了"，失败原因是"他不认同"
- 行为说服：对象是行为/习惯/行动，落点是"他在做，而且持续"，失败原因是"他知道该做，但做不到"
- 典型困境：对目标完全认同、对道理充分理解，就是"不行动"

## 二、重点：把重点放在行为上，而不是愿望

- 愿望："变得更健康" → 行为："多喝水"
- 愿望："获得男友关心" → 行为："让他经常给我发微信"
- 销售场景同理：客户"想找好方法"是愿望，"周四前把参数表发我"才是行为

## 三、三个子领域

### 1. 行为科学：为什么不行动？

典型场景（原文三例）：

- 员工答应做周报："好的，我周一交" → 周一没交，也没解释
- 客户答应推进项目："我们内部再对一下" → 三个月后还在"对一下"
- 团队要做知识库："这个方向挺好" → 试点停在试点，没人接

**核心洞察：戳破泡泡之前，所有的方法都不好**

- 所谓"好方法"= 不费力、没风险、不用付代价
- "不是不行动，我只是想找个好方法"——等待完美方案的本质：
  - 损失厌恶：不做 = 零损失
  - 承诺升级：不开始是最安全的退出方式
  - 拖延的情绪调节模型：不是懒，是不想难受
  - 完美主义 = 拖延的高级形态
- 表层："我在找方法"（听起来积极、理性、负责）；底层："我要保留退路"（实际是不承担选择的代价）

**鉴别：是在找方法，还是在拖延？**

- 判断标准：**有没有给出一个可验证的时间和动作**
- 真的在挑 → 会问"成本多少、效果怎么测"
- 在拖延 → 只问"有没有零风险的版本"

**七步解决法（原文落地话术表）**：

1. 接情绪："你担心的其实是 X，对吧"
2. 说破三角："不费力 + 没风险 + 不付代价，只有什么都不做能同时满足"——把"无限等待"变成"一个三选一的具体决定"，认知减负
3. 交出选择权："放弃哪一条更可以？"
4. 重新定义："不是要不要，是先做哪一段"
5. 低球 + 死人原则："周四前发我这一个数据就行"
6. 预先说服："第一次跑砸是正常的"——泡泡里的人往往是被"未来的难堪"吓住的，你先替他说了，他反而松了
7. 落到留痕：一份只有一行字的确认件

### 2. 行为设计

- 动机视角 & 能力视角（福格行为模型 B = MAP：动机×能力×提示，行为设计的圣经）
- 摩擦（《人性阻力》：四种心理摩擦）
- 金句：**人们以为：讨论对错，能让对方改变；实际是：谁痛苦，谁改变；容易改变 > 想改变；谁改变，谁受益**
- 书单：《福格行为模型》/《设计你的小习惯》（BJ Fogg，⭐⭐⭐）、《掌控习惯》（James Clear，身份认同+四定律，最好读）、《创新的本能·类比思维的力量》、《人性阻力》、《反直觉销售》

### 3. 行为经济学

- 人在陷阱里：判断与认知偏差——人会利用经验和捷径做判断，捷径节省精力，也可能造成系统性偏差
- 四个工具概念：偏差损失 / 锚定 / defaults（默认选项）· 承诺装置 / 助推 · 框架效应
- 书单：《偏差》《噪声》《思考，快与慢》

## 四、在 AKEEYO 面试工具中的应用（询盘环节落地）

- **拖延测试**：买家在第 5-7 轮（候选人始终没给实质报价时）抛"Let me check internally and get back to you."——考的就是"鉴别拖延 + 低球推进 + 落到留痕"：候选人若给出可验证的时间+动作（约周四通话/先寄样品/发确认邮件），买家配合推进；放任不管则买家冷淡收场
- **谈判力六信号之「小步推进」「留痕确认」「情绪确认」**：检测 candidate 是否用低球（sample/trial/pilot/first order）、留痕（confirm/in writing/I'll send）、接情绪（I understand/that makes sense）——对应七步法第 1/5/7 步
